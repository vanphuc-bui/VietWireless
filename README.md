# VietWireless

**Hiểu viễn thông bằng trực quan: từ tín hiệu đến 4G, 5G, NTN và 6G.**

VietWireless là nơi mình ghi lại những cách hình dung về wireless communication bằng tiếng Việt, từ các câu hỏi cơ bản cho tới 4G, 5G, NTN và 6G.

## Cách VietWireless giải thích một chủ đề

1. Bắt đầu bằng câu hỏi **tại sao cần nó?**
2. Cho người học **nhìn thấy hiện tượng** bằng đồ thị, animation hoặc interactive lab.
3. Giải thích trực giác bằng tiếng Việt, giữ thuật ngữ kỹ thuật tiếng Anh.
4. Sau đó mới đi vào toán học.
5. Kết nối với implementation: samples, waveform, transmitter/receiver chain và code.
6. Cuối cùng đối chiếu spec/public references khi phù hợp.

## Learning path đầu tiên

Âm thanh / hình ảnh → Signal → Sampling → Time domain → FFT → Frequency domain → I/Q samples → Modulation → OFDM → 4G / 5G.

Mục tiêu là trả lời rõ những câu hỏi rất cơ bản nhưng thường bị bỏ qua: signal thực chất là gì, FFT để làm gì, tại sao phải chuyển giữa time/frequency domain, và một I/Q sample thực sự biểu diễn điều gì.
